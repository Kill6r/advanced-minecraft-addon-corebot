# CoreBot Addon

`Advanced-Minecraft.js` is the CoreBot-side addon.

Before enabling it, configure:

- `License`
- `LicenseValidation.Endpoint`
- `LicenseValidation.ApiKey`
- `Database.Sync.Options.Mongo.Connect`
- `Database.Sync.Options.Mongo.Database`
- `Database.Sync.Options.Mongo.Collection`

The MongoDB database and collection must match the Minecraft plugin configuration.
